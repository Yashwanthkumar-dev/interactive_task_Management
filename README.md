
#  Taskr - Interactive Task Management System

A modern and responsive task management web application built using HTML, CSS, and JavaScript.
Taskr helps users efficiently manage daily tasks with features like task filtering, drag-and-drop sorting, dark/light mode, and localStorage persistence.

🌐 Live Demo:

  Taskr Live Demo -- > https://task-management-ivory-eta-54.vercel.app/

💻 GitHub Repository:

GitHub Repository --> https://github.com/Yashwanthkumar-dev/interactive_task_Management.git

## 📌 Project Overview
The main goal of this project is to build an interactive and user-friendly task management system using vanilla JavaScript without external frameworks.

This application allows users to:

Add tasks
Mark tasks as completed
Delete tasks
Filter tasks
Reorder tasks using drag and drop
Store tasks using localStorage
Switch between dark and light themes

The project focuses on:

Clean UI design
Responsive layouts
DOM manipulation
LocalStorage handling
Better code structure
Accessibility improvements
## 🚀 Features

Core Features:
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks 
     - Total
     - Pending
     - Completed
- Real-time digital clock
- Task statistics
- localStorage persistence
- Responsive design

✨ Advanced Features
- Drag and Drop task reordering
- Dark / Light mode toggle
- Animated UI effects
- Responsive layout for all devices
- Smooth hover interactions
- Modern glassmorphism inspired design

## 🛠️ Technologies Used

- HTML5
 - CSS3
 - JavaScript (Vanilla JS)
 - LocalStorage API
 - Flexbox
 - CSS Media Queries
